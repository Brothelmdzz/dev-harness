# 项目工作地图

初始化内容模板。替换成已核实入口，删除不适用项；未知写明未知。已有等价地图就复用，不要求复制这份文件。

## 团队共同入口

- 工作主入口与认领：任务位置、负责人来源、认领能力的文档/验证入口；未确认互斥时说明谁负责约定式分配及冲突协调。
- 有效决定与操作规范：需求/设计/ADR及实际操作手册入口，适用范围、替代关系和待确认冲突；沿上层资料的明确指向核对，不只登记介绍文档。
- 路线与集成：适用分支、目标分支、合并方式、共享接口责任、依赖和集成人的确定方法；如何核对候选实际进入目标。
- 知识来源：代码图/Wiki/架构入口，索引版本与工作区如何对应。

## 按任务读取

- 修改特定路径、接口或数据结构时，需要读取哪些约定；给具体触发条件和链接。
- 反馈与决定变化记在哪里，如何定位被影响的在途工作。
- 验证入口：现有测试/CI 定义与样例；补充常规命令没有表达的环境前提。
- MR、制品、部署与业务接纳：各自的原始回执/结构化查询入口和既定完成标准；哪些门禁必须通过、不可用时由谁决定处理方式。
- 交接位置：开发、测试和运维需要的入口；跨机器接收者如何取得候选和材料。忽略/未跟踪资料、未发布的本地版本或外部访问未知，标在对应入口旁；地图和宿主入口也需说明共享状态。

## 工具与个人准备

- 现有 CLI/Skill/API 的用法入口及目标平台，权限由当前用户环境提供。
- 个人安装、登录、网络和必要服务的检查方式；本机路径不充当团队事实。
- 未验证的连接、索引或访问能力及其影响；不存真实凭证。
