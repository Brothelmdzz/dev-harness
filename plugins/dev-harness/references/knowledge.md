# 代码与项目知识

每个 MR 检查知识影响，只有内容变化才更新。可用 CodeGraph、LLM Wiki、普通 Markdown 或现有检索；项目地图指定来源和实际操作方法，插件不绑定提供者。

结构关系从代码、配置和生成索引取证；知识解释保存业务意图、决定理由、被否决方案与跨组件约束。可以廉价从源码直接恢复的信息不重复抄写；完成日志不自动变成长期知识。

查询索引前核对仓库、路线/工作区、覆盖范围和索引对应版本。版本未知或落后时用源码核实，明确缺口。刷新已有索引须在当前授权和隔离能力内；首次安装/建索引不夹带在普通任务中。

未合入探索结果留在其候选范围，不能覆盖共享基线。自动图边、测试关联、文档 lint 和模型解释都不是运行成功证据；动态调用和外部系统的覆盖限制单独说明。

更新必要的架构、业务、接口或运维说明；理由失效时标出替代来源，避免新旧约定并存。已有资料正确则保留路径并引用。没有相关变化时记录无需更新的理由即可，不强制全仓扫描或重写 Wiki。
