# 未提交候选的传递

仅在需要跨工作区/机器传递未提交内容，或固定一份未提交评审候选时读取。普通同机接续核对原工作区即可；项目已有可取得、可识别的候选制品时直接复用。

优先使用项目现成的导出和校验工具。候选需包含基线、实际差异与取得位置，覆盖新增、修改、删除及改动归属；不要求为了交接提交代码。二进制文件、权限等影响行为的属性按项目需要保留。

采用补丁时，在独立临时副本按接收方使用方式实际应用，核对还原内容与候选一致，记录影响重放的换行口径；`--check` 只证明可应用。采用文件快照时核对内容清单和删除项，不能把文件名列表当成快照。保留原工作区和他人修改。

摘要、SHA 和字节数由工具从实际文件/原始回执生成，再核对最终输出；手抄值不能同时当来源和校验值。已有机器清单直接引用，业务说明只补充适用范围与限制。接收方无法取得基线、候选或证据时，明确交接缺项。
