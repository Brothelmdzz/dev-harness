# 5.0.0-alpha.4 团队版预发布

本版围绕共享资料的接续能力收敛规则，保留初始化、接手、变更检查和交接四个入口。

- 普通同机接续核对原工作区，跨环境传递或固定未提交评审候选时才读取补丁/快照说明；保留范围与证据的真实性要求。
- 交接复用现有任务和 MR，仅补下一动作所需的信息；交接材料备妥与接收者实际接续分开报告。
- 接手与方向变化核对当前有效决定，旧交接摘要不覆盖更新来源。公共接口重构前检查尚未提 MR 的在途工作，按已有负责人和平台协调受影响边界。
- 项目地图按实际需要裁剪，没有可选 CLI、平台 API 或代码图本身不构成缺口。明确初始化与只读核对的差别，保留原规则及共享状态核对。

## 产品范围

让不同开发者及其多个 Agent 依据当前项目约定接续工作。已有任务材料足够就引用，不要求每轮生成独立交接文档。

项目任务平台、Git、知识工具、CI及宿主分别保有原事实与执行能力。本包不管理Session生命周期，不实现任务分配器、互斥锁、图引擎或合并队列。

模型相关的补偿规则应随实际能力复查，特殊操作按需读取。项目分支策略、接口责任和门禁由项目约定决定，插件不承诺消除所有并发冲突。即使代码可以合并，任务前提也可能已经失效。

## 验证范围

包与格式检查验证结构和可移植性，不能证明模型遵循或团队效率。行为样本只支持实际观察到的路径，作者自述与验收方补做不算执行者通过。

本版 8 项包检查及 Plugin/四个 Skill 格式检查通过。最终用 Luna/max 进行一次有无插件的配对小样，每臂两个独立上下文、同一工作区，项目事实和批准修订相同，没有中途辅导。两臂作者都完成旧契约，接收者都依据新决定改变输出并保留仍有效的约束；原始快照与最终代码经独立行为检查通过。

本次没有显示效率优势：无插件两轮合计约 6.4 分钟，插件约 11.2 分钟，插件组 token 消耗也更高，并多读了可选资料。单次、顺序执行的小样不支持统计因果判断；本版不承诺提效。测试环境及评分曾需纠正，使用保留快照重算，没有修改执行者结果；跨机器、真正运行中的多人并发及自动发现覆盖率仍未验证。

Cloud、多账号长期协作、生产 CI/部署、真实图工具和其他宿主完整行为不在本次验收范围。历史通过记录不自动覆盖本版全部行为；本版保持有限验证的 alpha。

## 安装与回退

```sh
codex plugin marketplace add Brothelmdzz/dev-harness --ref v5.0.0-alpha.4
codex plugin add dev-harness@dev-harness-team
codex plugin list --marketplace dev-harness-team --json
```

使用支持这些命令的 Codex 版本。已配置同名固定版本来源时，先记录原 ref 与安装配置，再通过宿主的 marketplace 管理命令切换来源并安装；不手改缓存。安装后用新任务确认版本与四入口。已有项目复用原规则，需要建立地图时明确请求初始化；普通接手续作不重新初始化。

回退时用原固定版本来源重新安装，或通过宿主禁用团队版。保留已生成的项目资料、工作成果与历史版本；移除插件不等于删除项目资料。Claude manifest 已静态验证，模型行为验收以 Codex 为准。
