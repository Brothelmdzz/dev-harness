# 审查报告模板

## 单路报告（三份各一个）

输出到 `.claude/reports/review-{code|security|arch}.md`：

```markdown
# {维度} 审查报告

## CRITICAL
| # | 问题 | 文件 | 行号 | 说明 |
|---|------|------|------|------|

## WARN
| # | 问题 | 文件 | 行号 | 说明 |
|---|------|------|------|------|

## INFO
- {观察/建议}
```

## 汇总报告

输出到 `.claude/reports/final-review.md`：

```markdown
# 代码审查汇总

## CRITICAL 问题（必须修复）
| # | 问题 | 发现方 | 文件 | 行号 |
|---|------|--------|------|------|

## WARN 问题（建议修复）
| # | 问题 | 发现方 | 文件 | 行号 |
|---|------|--------|------|------|

## 三方对比
| 问题 | code | security | arch | 置信度 |
|------|------|----------|------|--------|

## 结论
- [x] 通过 / [ ] 不通过
- CRITICAL: {n} / WARN: {n} / INFO: {n}
```
