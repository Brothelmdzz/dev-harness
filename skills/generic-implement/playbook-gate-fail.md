# 门禁失败处理

## build 失败

1. 读编译错误信息（完整，不截断）
2. 定位出错的文件和行号
3. 修复编译错误
4. 重新运行 build 命令
5. 通过 → 继续跑 test；失败 → 回到 1

## test 失败

1. 只关注失败的测试（不看通过的）
2. 读失败测试的断言信息和堆栈
3. 判断是实现 bug 还是测试预期不对
4. 修复实现代码（优先）或调整测试（确认预期确实变了）
5. 只重跑失败的测试
6. 通过 → 跑全量确认无回归；失败 → 回到 1

## 3 次失败

停下报告用户，附上：
- 错误信息原文
- 已尝试的修复方案和结果
- 推测的根本原因
- 建议的人工排查方向

不得第 4 次用相同思路重试。
